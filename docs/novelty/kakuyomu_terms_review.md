# カクヨム利用規約レビュー

- 日付: 2026-08-03
- 対象: [カクヨムサービス利用規約](https://kakuyomu.jp/legal/tos)（2026-08時点）
- 対応: エピック #240（Q8: アクセス方針・リリース前規約レビュー）

## 確認方法

エピックでは「`kakuyomu.jp/terms` は Next.js CSR のためブラウザ確認が必要」としていたが、
実際の規約URLは **`/legal/tos`** であり、`/terms` は404を返す。
`/legal/tos` は **サーバーサイドで本文がレンダリングされており**、HTMLから直接確認できた
（リスク低減のため、リリース前にストア審査文脈での目視確認を推奨）。

## 関連条項と評価

| 条項 | 内容 | 評価 |
|---|---|---|
| 第12条 私的利用の範囲外の利用禁止 | 著作権法上の私的使用の範囲を超える複製・販売・出版は禁止 | **適合**。Noveltyは個人の読書用にオフラインキャッシュするのみ（私的使用の範囲内） |
| 第13条 営利目的利用の禁止 | 営利目的の利用・準備は禁止（申告・承認制） | **適合**。Noveltyは無料・非営利・広告なし。将来営利化する場合は要再確認 |
| 第14条 禁止事項 | リバースエンジニアリング等の禁止 | **適合**。公開HTMLの取得・解析はサイトのソースコード解析ではなく、一般的なWebクライアント挙動。robots.txtも該当ページを許可 |

## アクセス方針の適合性

| 方針 | 実装 | 状態 |
|---|---|---|
| robots.txt遵守 | `KakuyomuSite` がリクエスト前に禁止パス（`/read` 等）を検証して拒否 | ✅ |
| レート制限 | リクエスト間隔1秒（`KakuyomuRateLimiter`） | ✅ |
| キャッシュファースト | 本文はDBキャッシュし、差分（改稿日時）でのみ再取得 | ✅ |
| 取得対象 | 作品・目次・本文・検索・ランキング（すべてrobots.txt許可範囲） | ✅ |

## 結論

- **リスクは低い**と判断し、リリース方針（全開放）を維持する
- ストア公開前に、ユーザー側でブラウザによる規約の目視確認を推奨（第13条の営利利用・
  第14条の禁止事項の解釈が将来変更された場合は方針を見直す）
